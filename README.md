# MicrobiCompare - 微生物数据分析工具

## 简介

MicrobiCompare 是一个专业的微生物数据分析工具，专门用于进行两两比较分析。该工具具有现代化的用户界面和强大的数据分析功能。

## 功能特性

### 🎨 专业界面设计
- 现代化的Material Design风格
- 响应式布局，支持各种屏幕尺寸
- 直观的用户界面和交互体验
- 专业的配色方案和视觉元素

### 📊 数据分析功能
- **文件上传**: 支持CSV/TSV格式的数据文件
- **微生物列表过滤**: 可上传自定义的微生物列表进行筛选
- **多指标分析**: 支持reads_accum、rpm、abd等多种指标
- **阈值设置**: 可设置数据过滤阈值
- **样本选择**: 智能识别两个文件中的共同样本

### 📈 可视化功能
- **散点图**: 对数坐标散点图，清晰展示数据分布
- **参考线**: 自动添加y=x参考线
- **交互式图表**: 基于Plotly的交互式可视化
- **数据表格**: 详细的病原体RPM数据展示

### 📋 统计分析
- **单样本分析**: 针对选定样本的详细分析
- **批量统计**: 所有样本的汇总统计分析
- **比值计算**: 自动计算CSV1/CSV2比值
- **分类展示**: 分别展示高于/低于3倍的数据

### 💾 数据导出
- **图像导出**: 高质量PNG格式图表导出
- **表格导出**: CSV格式数据导出
- **批量导出**: 所有样本统计结果导出

## 技术栈

- **前端框架**: 原生HTML5 + CSS3 + JavaScript
- **图表库**: Plotly.js
- **数据解析**: PapaParse
- **图标库**: Font Awesome
- **样式**: 自定义CSS变量系统

## 使用方法

1. **下载模板文件**: 点击"下载模板文件"区域中的按钮，获取标准格式的CSV模板
2. **准备数据文件**: 按照模板格式准备您的数据文件
3. **上传数据文件**: 选择两个CSV/TSV格式的数据文件
4. **设置参数**: 选择分析指标、设置阈值
5. **选择样本**: 从下拉列表中选择要分析的样本
6. **生成图表**: 点击"绘图"按钮生成可视化图表
7. **查看结果**: 在右侧面板查看详细的病原体数据
8. **统计分析**: 点击"统计所有样本比较"进行批量分析
9. **导出结果**: 保存图表和统计数据
